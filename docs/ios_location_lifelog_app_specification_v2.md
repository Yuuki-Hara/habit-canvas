# iOS位置情報ライフログアプリ 仕様・要件整理ドキュメント

## 1. 全体像（コンセプトとゴール）

- **アプリ名称案:** （例：LifeCanvas、LogiStep など）
- **ターゲット:** ズボラだけど生活習慣や時間の使い方をしっかり管理（把握）したい人
- **コアコンセプト:**
  > **「完全放置（入力ゼロ・カメラ起動なし）」で生活を記録し、毎週日曜日に「先週との比較・ライフバランスの偏り」を通知してくれる、プライバシー完全保護のライフログアプリ。**
- **最大の特徴（強み）:**
  - サーバーレス（完全ローカル端末内処理）により、**App Storeのプライバシー欄で「データ収集なし」**を実現。
  - 広告なし・API代0円で、ユーザーにも開発者にも負荷がない。
  - ただ集計するのではなく、意味のあるまとまりとして整理してくれる

---

## 2. アプリ仕様（非機能要件）

- **プラットフォーム:** iOS (iPhone) 専用
- **開発言語 / フレームワーク:** Swift, SwiftUI, Swift Charts
- **データ保存:** 端末内データベース（SwiftData）
- **外部通信:** なし（※ただし、店名検索時にApple純正の `MapKit` のみOS経由で利用）
- **バックグラウンド処理:** `CoreLocation (CLVisit)` を用いた、バッテリーに優しい省電力の滞在検知
- **収益モデル:** 当面は無料（将来的に買い切り版や高度な分析機能のアンロックによるマネタイズを想定）

## 3. 機能要件（実装する機能一覧）

### ① 自動データ収集・判定機能（バックグラウンド）

- **滞在検知 (`CLVisit`):** ユーザーが同じ場所に一定時間（15〜20分以上）留まった際の位置情報を自動取得。
- **店名・カテゴリ自動特定 (`MapKit`):** 取得した座標周辺の施設情報を引き当て、自動でジャンルを判定。
- **ライフモード自動分類:** 滞在地を以下の6つに自動振り分け。
  1. 🏠 **自宅**（時間帯判定により自動特定）
  2. 🏢 **仕事**（時間帯判定により自動特定）
  3. 💪 **自己投資**（ジム・図書館・書店など）
  4. 🍽️ **外食**（カフェ・レストラン・居酒屋・スーパーなど）
  5. ⛺️ **レジャー**（映画館・スパ・公園・観光地など）
  6. 📦 **その他**（銀行・駐車場・未分類スポットなど）

#### 【ライフモード分類表】

| ライフモード    | 判定方法および主な MapKit公式カテゴリ (`MKPointOfInterestCategory`)                                                         | 具体例・対象施設                                                    |
| :-------------- | :-------------------------------------------------------------------------------------------------------------------------- | :------------------------------------------------------------------ |
| **🏠 自宅**     | 位置情報の時間帯判定により自動特定                                                                                          | 深夜〜早朝に継続滞在するプライベート空間                            |
| **🏢 仕事**     | 位置情報の時間帯判定により自動特定                                                                                          | 平日日中などに継続滞在するオフィスや学校、病院など                  |
| **💪 自己投資** | `fitnessCenter`, `library`, `bookstore`, `museum`, `planetarium`                                                            | ジム、フィットネスセンター、図書館、書店、美術館                    |
| **🍽️ 外食**     | `cafe`, `restaurant`, `bakery`, `brewery`, `foodMarket`, `distillery`, `winery`                                             | カフェ、レストラン、ファミレス、居酒屋、パン屋、スーパー、コンビニ  |
| **⛺️ レジャー** | `movieTheater`, `theater`, `nightlife`, `park`, `amusementPark`, `beach`, `stadium`, `castle`, `nationalMonument`           | 映画館、劇場、バー・クラブ、公園、テーマパーク、スタジアム、観光地  |
| **📦 その他**   | `atm`, `bank`, `carRental`, `evCharger`, `gasStation`, `parking`, `postOffice`, `restroom`, `laundry` および判定不能（nil） | 銀行、ATM、ガソリンスタンド、駐車場、コインランドリー、その他未分類 |

### ② 手動学習・補正機能

- **判定ズレの修正:** 雑居ビル等で場所やモードの判定がズレた際、ユーザーが1タップで正しいモードに変更できる機能（※一度修正した座標は次から自動学習）。
- **自宅・職場の初期学習:** 初回セットアップ時、または週間レポートでの確認を通じて「ここが自宅・職場」を確定させる機能。

### ③ レポート・通知機能

- **日曜夜の週間レポート:** 毎週日曜日の夜に「今週のライフバランス診断（アクション系ライフモードの**滞在回数・件数ベース**の集計と先週比の比較）」を通知・表示。
