# habit-canvas

habit-canvas は、位置情報をもとに「あなたの生活の使い方」を自動で記録し、毎週のライフバランスを見える化する iOS アプリです。

単に「どこにいたか」を残すのではなく、

- 自宅なのか
- 仕事場なのか
- 自分の成長につながる場所なのか
- 外食やレジャーが多いのか

といった生活の文脈まで整理して、あなたの人生のクセや偏りに気づけるようにします。

---

## このアプリは何ができるのか

habit-canvas は、ユーザーが何も入力しなくても、自動で生活ログを作ります。

例えば、次のようなことが起こります。

- 15〜20 分以上同じ場所に滞在したら、その場所を自動で記録
- その場所が「自宅」「仕事」「自己投資」「外食」「レジャー」「その他」のどれに近いかを自動判定
- 「最近、外食が多い」「自己投資の場が少ない」など、週単位で生活の傾向を見える化
- 毎週日曜日の夜に、先週と比べたライフバランスの変化を通知

つまり、habit-canvas は「位置情報アプリ」ではなく、

「あなたの一週間の生活の使い方を、勝手に記録して、自然に見直せるようにするアプリ」

です。

---

## こんな人に向いている

- 生活習慣や時間の使い方を少しでも把握したい
- 毎日手入力で記録するのが面倒
- ただの歩数やカレンダーではなく、「どこにどれくらい時間を使っていたか」を知りたい
- 生活に偏りがあるか気にかけたい
- プライバシーを重視したい

---

## 何がユーザーの価値になるのか

### 1. 「入力ゼロ」で記録できる

アプリに何も記録しなくても、生活の痕跡が自動で残ります。

カレンダーを手で埋める必要はありません。毎日の行動が、自然に記録されます。

### 2. 生活の意味を「場所」で理解できる

生活はただの時間ではなく、どこで何をしていたかでかなり変わります。

habit-canvas は、

- 自宅で過ごす時間
- 職場にいる時間
- 自分の成長につながる場所に行く時間
- 食事や休息の時間

といった生活の構造を、場所ごとに見えるようにします。

### 3. 週単位で「改善ポイント」を見つけられる

アプリの目的は、ただログを残すことではありません。

毎週、

- 外食が増えてないか
- 自己投資の時間が減ってないか
- レジャーや休息が足りているか

といった傾向に気づけるようにします。これは、生活を「なんとなく」ではなく、

「自分のバランスを見直すきっかけ」

になります。

---

## どういう体験を提供するのか

### 1. バックグラウンドで生活を観測

アプリは、ユーザーが意識していない間にも、滞在場所と滞在時間を記録します。

### 2. 場所ごとに生活のカテゴリを整理

滞在先は次のようなライフモードに振り分けます。

- 🏠 自宅
- 🏢 仕事
- 💪 自己投資
- 🍽️ 外食
- ⛺️ レジャー
- 📦 その他

これにより、単なる「場所」ではなく、生活の文脈として理解できます。

### 3. 週次レポートで気づきを届ける

日曜日の夜に、今週の生活を振り返るレポートを出します。

例えば、

- 外食: +2 回
- 自己投資: -1 回
- レジャー: ほぼ変化なし

といった形で、先週との比較を簡潔に伝えます。

## 画面のイメージ

### タイムライン画面

「今日や今週、どこにどれだけいたか」を時系列で確認できます。

- 滞在場所
- 滞在時間
- 判断の正しさを微修正できる

### 週間レポート画面

「今週の生活バランス」を一目で見るための画面です。

- 外食・自己投資・レジャーの件数
- 前週との比較
- 偏りや変化の可視化

---

## 他のアプリと違うところ

habit-canvas の強みは、「記録する手間がない」ことと、「生活の文脈まで整理する」ことです。

- 手入力が不要
- 位置情報から自動で生活を記録
- 外部サービスにデータを送らない
- 生活を「ただのログ」ではなく「分析可能な生活パターン」に変える

また、ユーザーが誤判定に気づいたときには、一時的に修正できる仕組みも用意し、

「自分の生活に合わせて学習していく」

アプリとして成長していきます。

## 技術的な方向性

実装の中心は以下の技術です。

- Swift
- SwiftUI
- SwiftData
- CoreLocation
- MapKit
- Swift Charts

特徴として、位置情報の処理やデータ保存は端末内で完結し、外部通信は基本的に行いません。

そのため、

- プライバシーを守れる
- App Store 上での説明がしやすい
- 低コストで運用しやすい

という利点があります。
